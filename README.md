# CrimeWallets

CrimeWallets is a periodically refreshed list of Solana wallets that appear on a wallet marketplace and may be used in coordinated token-bundling activity.

The list is provided in a format compatible with Axiom's wallet tracker.

## Import into Axiom

1. Download [`axiom_wallets.json`](./axiom_wallets.json).
2. Open **Trackers** in Axiom.
3. Select **Import**, choose the downloaded file, and confirm the import.

> [!WARNING]
> Exercise caution with memecoins in which these wallets appear. A wallet's presence is a risk signal, not proof that a token or its creators are malicious. Always do your own research.
